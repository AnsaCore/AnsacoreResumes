Business Intelligence Consultant / Data Engineer at Cegeka - Data Solutions
09/2020 - 05/2022
During my first six months at Cegeka, the focus was in-house development of the internal business insights solution called CBI. CBI uses ERP data from Microsoft Dynamics 365 / AX2012. This ERP data is migrated via SQL Server Integration Services and loaded into different SQL Server Analysis Services cubes (tabular/multidimensional). Each cube represents a specific data mart (e.g. Finance, Quality, Order To Cash, etc.). The final step is visualisation on these Tabular cubes through Power BI. Besides the on-premises variant, there is also a cloud version of CBI. The main difference here is the orchestration of the daily load processes. The on-premise solution made use of a SQL Agent Job whereas the cloud version uses Azure Datafactory.

After six months, I was assigned the KRC Genk project which was an entire cloud project. The main goal of this project was to integrate data from several external partners into one data platform which contained the single version of the truth regarding merchandising, ticketing, consumption data etc. The technologies on this project were Azure Datafactory and Automation Runbooks (orchestration of the ELT processes), Azure Databricks (PySpark related code for data manipulation, cleanup etc.) and Azure SQL Server / Azure Data Lake Storage (for data storage). This project was very different in comparison to the CBI project. It was mostly programming in Python to prepare the data for end-users (through a bronze, silver and gold data vault layer) whereas CBI uses a more traditional data warehousing approach (staging, history, facts and views).

Finally during my career at Cegeka, I also studied and received several Azure certificates (Azure Data Fundamentals, Azure Data Engineer Associate & Azure Data Analyst Associate). I also expanded my knowledge of Python, the cloud in general and Power BI through several DataCamp & U2U courses.
